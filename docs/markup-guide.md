# 마크업 작성 가이드

네이버 블로그 업로더는 **커스텀 마크업 문법**을 사용합니다. 표준 Markdown이 아닌,
네이버 스마트에디터의 서식(볼드/밑줄/하이라이트 등)에 1:1 매핑되는 규칙이에요.

## 기본 규칙

| 마크업 | 네이버 블로그 결과 | 예시 |
|---|---|---|
| `**텍스트**` | **굵게(Bold)** | `**중요한 포인트**` |
| `__텍스트__` | <u>밑줄(Underline)</u> | `__강조할 내용__` |
| `*텍스트*` | *기울임(Italic)* | `*살짝 부드러운 톤*` |
| `==텍스트==` | 노란 하이라이트 | `==핵심 키워드==` |
| `##텍스트##` | 소제목 (구분선 자동 추가) | `##첫 번째 단락##` |
| `>>텍스트<<` | 인용구 블록 | `>>기억할 만한 한 줄<<` |

## 제목 (첫 줄)

파일의 **첫 줄**에 제목을 넣어야 합니다. 두 가지 형식 모두 허용:

```markdown
# 이것은 Markdown 스타일 제목입니다
```

또는

```markdown
##이것은 네이버 스타일 제목입니다##
```

> 업로더는 첫 번째로 발견한 `# ` 또는 `##...##` 을 제목으로 쓰고, 본문에서 같은 줄이 중복되면 제거합니다.

## 조합 사용

마크업은 **조합**할 수 있습니다. 가장 바깥쪽부터 안쪽 순서로 적용됩니다.

| 조합 | 결과 |
|---|---|
| `**__텍스트__**` | **<u>굵게 + 밑줄</u>** |
| `**==텍스트==**` | **노랗게 + 굵게** |
| `__==텍스트==__` | <u>노랗게 + 밑줄</u> |

## 인용구 사용 팁

인용구(`>>...<<`)는 한 줄 단위로 씁니다.

```markdown
##오늘의 교훈##

오늘 배운 것은 하나입니다.

>>꾸준함이 재능을 이긴다<<

이 문장을 매일 책상에 붙여두겠습니다.
```

## 금지 / 주의 사항

- `**`, `__`, `==`, `##`, `>>`, `<<` 기호를 **본문 텍스트로 그대로 쓰면** 서식으로 해석됩니다.
  숫자 표기(`10**2`)나 코드 조각처럼 리터럴이 필요하면 한 글자를 공백으로 분리하세요 (`10 ** 2`).
- 마크업은 **한 줄 안에서 완결**되어야 합니다. 줄바꿈을 넘어 걸치면 무시됩니다.
- 소제목(`##...##`) 뒤에 자동으로 구분선이 들어갑니다. 구분선을 추가로 넣지 않아도 됩니다.
- 이미지는 별도로 처리됩니다. 마크다운의 `![alt](path)` 구문은 현재 지원하지 않습니다. 필요 시 `src/services/NaverBlogService.js`의 이미지 업로드 로직을 참고하세요.

## 전체 예시

아래는 바로 업로드 가능한 완성 샘플입니다. `files/ready/sample-post/` 에 있는 샘플과 동일한 형식이에요.

```markdown
# 마크다운 자동 업로드 테스트 글

##첫 번째 섹션##

이 글은 **네이버 블로그 업로더** 테스트를 위한 샘플입니다.
업로더는 __커스텀 마크업__ 을 ==자동으로 스마트에디터 서식== 으로 변환합니다.

##기능 요약##

- **볼드**, __언더라인__, *이탤릭*
- ==형광펜 하이라이트==
- 조합도 가능: **__중요하고 진한 밑줄__**

>>작은 꾸준함이 큰 변화를 만든다<<

테스트가 끝나면 파일은 `files/done/` 으로 이동됩니다.
```
